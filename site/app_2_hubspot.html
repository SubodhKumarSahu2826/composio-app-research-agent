HubSpot APIs | Authentication methods on HubSpot

HubSpot's APIs support authentication using OAuth and private app access tokens, in addition to other key types like Developer API keys and Personal Access Keys.

There are two ways to authenticate calls to HubSpot’s APIs: OAuth, and private app access tokens. Below, learn more about each method and how to include it in your code for authorization. [...] The affected key and token types are listed below: Developer API keys created within your app developer account. Personal Access Keys used to authenticate commands in the HubSpot CLI. Private access tokens used to authenticate requests in a private app. SMTP tokens used for sending transactional emails.

How to Connect with the HubSpot API

HubSpot's API uses REST endpoints with JSON payloads and OAuth 2.0, often utilizing Bearer tokens for authorization, though its OAuth implementation can have specific quirks.

HubSpot's API looks modern on the surface. REST endpoints, JSON payloads, OAuth 2.0, webhooks. [...] 'Authorization': `Bearer ${accessToken}` [...] HubSpot uses OAuth 2.0, which sounds standard until you realize their implementation has its own special flavor. You need three things before you even start: a developer account (separate from your regular HubSpot account), an app registration, and the patience of a saint.
